# Python კურსი — 40 შეხვედრა (React SPA)

React + Vite + Tailwind აპლიკაცია, ჩაშენებული Pyodide Python ინტერპრეტატორით.
ამჟამად სრულად შევსებულია **შეხვედრა #1**; დანარჩენი 39 შეხვედრა უკვე ჩანს
ნავიგაციაში, სათაურებით, და ელოდება შიგთავსს (იხ. "შემდეგი ნაბიჯი" ქვემოთ).

## 🚀 გაშვება ლოკალურად

```bash
npm install
npm run dev
```

## 🌐 GitHub Pages-ზე დასაჰოსტად

1. შექმენი ახალი GitHub რეპოზიტორი, მაგ. `python-course`.
2. `vite.config.js`-ში `base` ველი შეცვალე შენი რეპოს სახელზე:
   ```js
   base: '/python-course/',
   ```
3. დააინსტალირე დამხმარე პაკეტი და ატვირთე კოდი:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/USERNAME/python-course.git
   git push -u origin main
   ```
4. გაუშვი დეპლოი (ეს ააგებს `dist/`-ს და გამოაქვეყნებს `gh-pages` შტოში):
   ```bash
   npm run deploy
   ```
5. GitHub-ის რეპოს **Settings → Pages**-ში აირჩიე Source: `gh-pages` branch.
6. რამდენიმე წუთში საიტი ხელმისაწვდომი იქნება:
   `https://USERNAME.github.io/python-course/`

> 💡 Pyodide იტვირთება CDN-იდან (jsdelivr), ასე რომ ინტერნეტთან კავშირი
> საჭიროა პირველი გაშვებისას — შემდეგ ბრაუზერი მას ქეშავს.

## 📁 პროექტის სტრუქტურა

```
src/
  data/lessons.js        ← 40-ვე შეხვედრის მეტამონაცემები + lesson1Content
  components/
    Sidebar.jsx           ← ნავიგაცია ორ ბლოკად (საფუძვლები / OOP)
    LessonView.jsx        ← შეხვედრის რენდერი (agenda, თეორია, კოდი, სავარჯიშო, ქვიზი)
    PythonPlayground.jsx  ← Pyodide-ზე დაფუძნებული ცოცხალი კოდის რედაქტორი
    Quiz.jsx               ← თვითშემოწმების ქვიზის კომპონენტი
  App.jsx                 ← SPA გარსი, აქტიური შეხვედრის state + localStorage
```

## ➕ შემდეგი ნაბიჯი: ახალი შეხვედრების დამატება

ორი ცვლილება გჭირდება ახალი შეხვედრის დასამატებლად:

1. `src/data/lessons.js`-ში დაამატე `lessonXContent` ობიექტი (ისეთივე ფორმატით,
   როგორც `lesson1Content`).
2. `src/components/LessonView.jsx`-ში დაამატე მარტივი switch/map, რომელიც
   შესაბამის `lessonXContent`-ს ირჩევს `lesson.id`-ის მიხედვით (ამჟამად მხოლოდ
   `lesson1Content` არის მიბმული — Claude-ს სთხოვე ეს switch-იც დაწეროს, როცა
   პირველ დამატებით შეხვედრას მოგცემს).

## 🧩 Prompt-შაბლონი შემდეგი შეხვედრებისთვის

დააკოპირე და შეავსე ეს შაბლონი, რომ Claude-ისგან მიიღო შემდეგი შეხვედრის
სრული, ჩასართავი კოდი ზუსტად ისეთივე ფორმატით, როგორც შეხვედრა #1-ია აწყობილი:

```
გთხოვ, დამიწერე შეხვედრა #[ნომერი]-ის სრული შიგთავსი ჩემი Python-ის
სასწავლო SPA აპლიკაციისთვის (React + Vite + Tailwind + Pyodide).

კონტექსტი:
- თემა: [თემის დასახელება lessons.js-დან, მაგ. "ცვლადები და მონაცემთა ტიპები"]
- ბლოკი: [basics / oop]
- ტიპი: [theory / project]
- სამიზნე ასაკი: 11-14 წელი

მოთხოვნები:
1. დამიწერე ახალი კონსტანტა lesson[ნომერი]Content ზუსტად იმ ფორმატით,
   რა ფორმატითაც არის lesson1Content obj src/data/lessons.js ფაილში
   (agenda, theory, codeExamples, exercises [Easy/Medium/Challenge], quiz,
   challenge ველებით).
2. დაიცავი 60-წუთიანი სტრუქტურა: 00-15 თეორია/ანალოგიები, 15-35 კოდი &
   დემო, 35-50 პრაქტიკა/ქვიზი, 50-60 გამოწვევა.
3. თუ ეს "project" ტიპის შეხვედრაა (გამეორება + რეალური პროექტი), თეორიის
   ნაწილი შეცვალე წინა თემების მოკლე შეჯამებით და კოდის მაგალითები/
   სავარჯიშოები ააგე ერთიანი მინი-პროექტის გარშემო.
4. ენა და მაგალითები მაქსიმალურად მარტივი და საინტერესო იყოს 11-14 წლის
   მოსწავლისთვის — ანალოგიები ყოველდღიური ცხოვრებიდან.
5. კოდი უნდა იყოს 100%-ით მზა და დამატებადი, placeholder-ების გარეშე.
6. დამატებით მითხარი, საჭიროა თუ არა LessonView.jsx-ში
   switch/map-ის განახლება ახალი lessonXContent-ის მისაბმელად და თუ
   საჭიროა — მომეცი ის str_replace-ისთვის მზა კოდის ფრაგმენტიც.
```

შენიშვნა: რაც უფრო მეტ შეხვედრას დაამატებ, მით უფრო დიდი გახდება
`lessons.js`. სასურველია პერიოდულად სთხოვო Claude-ს, რომ თითოეული ახალი
თემატური ბლოკის დასრულებისას გამოცადოს აპლიკაცია (`npm run dev`) და
დაარწმუნდე, რომ ნავიგაცია და Playground გამართულად მუშაობს.
